Scientific transparency

The YouthCraft Model Registry.

Every number you see is the result of plain arithmetic on documented parameters. This registry lists them, says where each one comes from, and is honest about which are still assumptions.

Read the science →How it works
01 · Principles

Rule-based, traceable, editable.

⌁

Traceable

Each answer option has a code, a Life-days value and a recoverable value, and each question lists its reference and evidence rating.

∑

No black box

The model multiplies and adds documented values. It does not use machine learning to produce Life-days.

✎

Honest status labels

Every parameter is marked as source data, a judgement, an assumption, a convention or a default under review.

04 · Evidence quality

12 High · 60 Moderate · 128 Low.

Evidence ratings are assigned per question. The mix is weighted toward limited or emerging evidence, and the model should be read with that in mind.

05 · Open items

What we are still validating.

  • Hazard ratios. Current values are scaled from each option’s share of maximum Life-days. They need to be replaced with point estimates and confidence intervals extracted from the primary studies.
  • Reference links. Every question lists a reference title. For 48 of the 200, the link goes to the specific paper; the rest currently link to the general PubMed site while specific links are added.
  • Adherence factor and cap. Both are product assumptions and may change as evidence and user data allow.
  • Age and sex. Hazard ratios are assumed constant across adult ages, and the sex modifier is 1.0 throughout.
  • Clinical review. Feedback ratings, red-flag alert wording and the suggested defaults for action targets are drafts awaiting review by a qualified clinician.
